Console-based Tic-Tac-Toe with AI
A classic Tic-Tac-Toe game built in Java that features a single-player mode against an AI opponent. This project demonstrates foundational programming concepts, including game state management, input handling, and basic game theory logic.

Features
Player vs. Player: Challenge a friend in a local two-player mode.

Player vs. AI: Play against a computer opponent with integrated decision-making logic.

Interactive Console UI: A user-friendly command-line interface to manage game turns and display the board.

Technologies Used
Language: Java

Interface: Console/Command Line

How to Run
Clone the repository:

Bash
git clone https://github.com/kingstan002/Console-based-Tic-Tac-Toe-Game-with-AI.git
2.  **Open the project:** Open the folder in your favorite Java IDE (e.g., IntelliJ IDEA, Eclipse, or VS Code).
3.  **Compile and Run:** Navigate to the main class file and run the application. Follow the on-screen prompts to select your game mode and make your moves.
